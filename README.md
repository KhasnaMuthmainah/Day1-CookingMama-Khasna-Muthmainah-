Building with AI, Managing Change with GitHub

Pemateri: Nugi Farhan

Prompt Engineering: Teknik menyusun instruksi AI agar menghasilkan jawaban yang tepat dan relevan.
Struktur prompt yang baik terdiri dari Role, Task, Context, dan Format.
Git: Sistem untuk melacak dan mengelola perubahan file atau proyek.
GitHub: Platform online untuk menyimpan repository dan mendukung kolaborasi.
Mengenal konsep Git Workflow, yaitu Working Directory, Staging Area, dan Repository.
Mempelajari perintah dasar Git seperti git init, git add, git commit, git push, dan git pull.
AI dapat dimanfaatkan untuk membantu membuat aplikasi sederhana, sedangkan GitHub membantu mengelola perkembangan proyek.
2. Kurikulum Merdeka di Perguruan Tinggi (MBKM & MSIB)
Hal-hal yang saya dapatkan:
MBKM: Memberikan kesempatan kepada mahasiswa untuk belajar di luar program studi melalui berbagai kegiatan yang dapat dikonversikan menjadi SKS.
Terdapat delapan bentuk kegiatan MBKM, di antaranya magang, pertukaran pelajar, penelitian, wirausaha, dan proyek independen.
MSIB: Program magang dan studi independen bersertifikat yang melibatkan mitra industri.
Mengenal tiga metode pembelajaran: Project-Based Learning (PjBL), Problem-Based Learning (PBL), dan Case-Based Learning (CBL).
MBKM dan MSIB memberikan kesempatan memperoleh pengalaman industri, meningkatkan kompetensi, membangun portofolio, serta memperluas relasi profesional.
Mahasiswa perlu mempersiapkan CV, portofolio, kemampuan akademik, dan mengenali arah karier sebelum mengikuti program.
Kesimpulan
Kedua workshop memberikan wawasan mengenai pentingnya menguasai teknologi, memanfaatkan AI, mengembangkan keterampilan praktis, serta aktif mencari pengalaman di luar perkuliahan sebagai bekal memasuki dunia profesional.
